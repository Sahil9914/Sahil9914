### 🌟 Featured Projects

**[Codebase Chat — AI Codebase Assistant using RAG](https://github.com/Sahil9914/codebase-chat)**
`Python` `FastAPI` `Streamlit` `Qdrant` `Gemini API` `Hugging Face Embeddings` `GitPython`
End-to-end RAG system with a FastAPI backend that clones and indexes any GitHub repo for semantic code search and Q&A. Uses AST-based structural chunking (function/class-level, not naive text splitting) paired with BAAI embeddings and a Qdrant Cloud vector database for fast similarity search. Redesigned Streamlit dashboard with chat history and source citations to visualize retrieval results and search relevance.

**[Pathological Gait & Activity Recognition](https://github.com/Sahil9914/gait-detection-cnn-bilstm)**
`Python` `TensorFlow` `CNN` `BiLSTM` `Transformer` `Autoencoder` `Scikit-Learn`
Deep learning system for human activity recognition — cleaned 2.1M+ multi-sensor time-series samples and applied CNN+BiLSTM and Transformer models on HuGaDB (12 classes), reaching 91.89% accuracy. Added unsupervised anomaly detection via Autoencoder (96% normal specificity, 100% anomaly recall on simulated pathological gait patterns), evaluated with precision, recall, F1-score, and confusion matrix across all 12 classes.
